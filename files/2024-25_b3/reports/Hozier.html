1 Introduction

Hozier, born Andrew John Hozier-Byrn, is an acclaimed singer-songwriter and musician. He was born on March 17, 1990, in Bray, Ireland. He rose to fame with his 2013 hit single “Take Me to Church”. Hozier’s music combines elements of indie rock, blues, soul, and folk. He has released three albums throughout his career which have earned him several award nominations, including a Grammy Award nomination.

1.2 Spotify Data

In this exploratoy data analysis, I examine track data sourced from Spotify to uncover insights into Hozier’s discography by looking at key audio and streaming features.

1.2.1 Date Pre-Processing

I imported two csv files, the Spotify Artist dataset and a dataset I created myself from streaming counts on Spotify, into R.

I removed duplicates due to the data including ‘live’ versions. I also change the column header ‘Song.Title’ to ‘track_name’ in my Streams dataset so it would correspond with the Artist dataset. Finally, I used the setdiff function to find and remove any difference in track titles.

The final result is a combined dataset with unique tracks and streaming data.

correlation_matrix <- cor(Numeric_data)

# Compute the p-values for each correlation
cor_p_values <- cor.mtest(Numeric_data)$p

# Set significance threshold (e.g., p < 0.05)
sig_threshold <- 0.05

# Create a custom function to color the correlation coefficients
cor_color <- function(cor, p) {
  if (p < sig_threshold) {
    return("red")   # Color for significant correlations
  } else {
    return("black") # Color for non-significant correlations
  }
}

# Apply the color function to each correlation coefficient
cor_text_colors <- mapply(cor_color, correlation_matrix, cor_p_values)

# Visualize the correlation matrix with the customized text color

         method = "color",

#3 d) Investigating energy & valence trend further with correlation tests + barchart 

#Formula for correlation stats - energy
cor_test_by_album <- function(No_extras) {
  test <- cor.test(No_extras$track_number, No_extras$energy, use = "complete.obs")
  tibble(correlation = test$estimate, p_value = test$p.value)
}

#Apply cor.test to each album - energy
album_correlation_tests <- No_extras %>%
  group_by(album_name) %>%
  nest() %>%
  mutate(results = map(data, cor_test_by_album)) %>%
  unnest(results) %>%
  select(album_name, correlation, p_value)

#Formula for correlation stats - valence
cor_test_by_album2 <- function(No_extras) {

5.1 Streams and Loudness

The trend in loudness is presumably based on the idea that louder songs are associated with greater popularity.

Let’s test this! We’re going to remove outliers from the Streams variable because certain tracks have significantly higher streams due to use in popular media, trends, etc.

# Calculate the first and third quartiles and IQR
Q1 <- quantile(combined_data$Streams, 0.25, na.rm = TRUE)
Q3 <- quantile(combined_data$Streams, 0.75, na.rm = TRUE)
IQR_value <- IQR(combined_data$Streams, na.rm = TRUE)

# Define the range for non-outliers
lower_bound <- Q1 - 1.5 * IQR_value
upper_bound <- Q3 + 1.5 * IQR_value

# Filter the data to exclude outliers
NoOutlier <- combined_data %>%
  filter(Streams >= lower_bound & Streams <= upper_bound)

ggplot(data = NoOutlier, aes(x = loudness, y = Streams)) +
  geom_point(color = "blue") +          
  labs(
    title = "Scatterplot of Loudness vs Streams", 
    x = "Loudness", 
    y = "Streams"
  ) +
  theme_minimal() +                      
  geom_smooth(method = "lm", color = "red") 
# Perform correlation test between loudness and streams
cor_test_result2 <- cor.test(NoOutlier$loudness, NoOutlier$Streams)

correlation_coefficient <- cor_test_result2$estimate
p_value <- cor_test_result2$p.value
conf_interval_lower <- cor_test_result2$conf.int[1]
conf_interval_upper <- cor_test_result2$conf.int[2]

# Create a data frame for the kable table
cor_test_table <- data.frame(
  Metric = c("Correlation Coefficient", "P-value", "Confidence Interval Lower", "Confidence Interval Upper"),
  Value = c(correlation_coefficient, p_value, conf_interval_lower, conf_interval_upper)
)
